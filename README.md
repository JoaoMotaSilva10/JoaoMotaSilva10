# Olá, eu sou o João Pedro 👋

Desenvolvedor **backend** e de **banco de dados**, estudante de Análise e Desenvolvimento de Sistemas na **FATEC Carapicuíba**.

Hoje trabalho como estagiário de banco de dados na **TOTVS Juritis**, onde participo da implantação dos sistemas **LegalDesk** e **Sisjuri** em clientes e cuido de ambientes Oracle, SQL Server e PostgreSQL: escrevo e otimizo SQL e PL/SQL, faço backup e migração de dados com Oracle Data Pump, monitoro tablespaces e investigo incidentes em bancos e aplicações rodando em Windows Server, Linux, OCI e AWS.

Fora do trabalho, construo APIs REST com **Java e Spring Boot**.
